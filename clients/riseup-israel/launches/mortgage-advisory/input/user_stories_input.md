אמרתי לה שאני צריכה שהיא תגיד לי בכמה אני הולכת להוזיל ושאני צריכה לדעת מה הסכום כדי להבין מול התשלום שלכם - אני צריכה לדעת שזה אפשרי גם לפי הרייזאפ שלי. היא הסבירה בכמה היא תוזיל את המשכנתא והסבירה לפי חלוקה לתשלומים את הקיזוז - זה נתן אוויר.
